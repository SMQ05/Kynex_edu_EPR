### A5: OpenRouter AI Service
Create app/Services/Ai/OpenRouterService.php

OpenRouter API is compatible with OpenAI SDK format:
  Base URL: https://openrouter.ai/api/v1
  Auth: Bearer {OPENROUTER_API_KEY} (from central .env, 
        NOT per-tenant — KynexEdu pays OpenRouter, 
        bills schools on usage)

Constructor accepts: Tenant $tenant
  Checks $tenant->ai_enabled — throws if not enabled
  Checks $tenant->ai_used_this_month_paisas < 
        $tenant->ai_monthly_budget_paisas — throws if over budget

Method: chat(string $systemPrompt, string $userMessage, 
             string $context = ''): string
  POST https://openrouter.ai/api/v1/chat/completions
  Headers:
    Authorization: Bearer {env OPENROUTER_API_KEY}
    HTTP-Referer: {APP_URL}
    X-Title: KynexEdu
  Body:
    model: $tenant->ai_model (default: 'google/gemini-flash-1.5')
    messages: [
      {role: system, content: $systemPrompt},
      {role: user, content: $context . "\n\n" . $userMessage}
    ]
    max_tokens: 1000
  
  After response: calculate approximate cost, 
  update tenant->ai_used_this_month_paisas in central DB.
  Log usage to ai_usage_logs table (migration below).
  Return response text.

Create migration: create_ai_usage_logs_table (CENTRAL DB)
  id (ulid), tenant_id, model_used, 
  prompt_tokens int, completion_tokens int,
  estimated_cost_paisas unsignedBigInt,
  feature_used string (e.g. 'admission_assistant', 
                       'parent_portal_guide', 'admin_overview'),
  timestamps

Add OPENROUTER_API_KEY to .env.example with comment:
"# OpenRouter API key — KynexEdu account pays this, 
  usage billed to schools monthly"

Note: Default model for new tenants: google/gemini-flash-1.5
(cheapest capable model on OpenRouter — ~$0.075/1M tokens)
Tenant can be upgraded to gpt-4o or claude-3-5-sonnet 
from SaaS admin panel.
