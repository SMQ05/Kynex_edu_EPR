### 2.2 `/var/www/kynex/docker/certbot-renew.cron` (0.7 kB)

Twice-daily renewal cron. `--post-hook` is wrapped in `flock -w 30`
against `/var/lock/nginx-mutate.lock` so the reload cannot race with
provision-cert.sh / remove-cert.sh (rev2 fix #1).

```
SHELL=/bin/bash
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

# Phase 1.5 — twice-daily Let's Encrypt renewal sweep.
# LE recommends two attempts/day at randomised offset. Container time is
# UTC; 03:17 and 15:17 keep us out of the herd.
#
# The --post-hook reload is wrapped in flock against the global nginx
# mutate lock so it cannot race with provision-cert.sh / remove-cert.sh.
# `flock -w 30` waits up to 30s for the lock; if it can't acquire it
# exits non-zero (logged below) — fail-loud, never hang silently.
17 3,15 * * * root /usr/bin/certbot renew --quiet --post-hook "/usr/bin/flock -w 30 /var/lock/nginx-mutate.lock /usr/sbin/nginx -s reload" >> /var/log/certbot-renew.log 2>&1
```

### 2.3 `/var/www/kynex/docker/provision-cert.sh` (9.0 kB)

```bash
#!/usr/bin/env bash
#
# provision-cert.sh — issue / renew a Let's Encrypt cert for a custom
# domain and write the corresponding nginx server block.
#
# Phase 1.5 — invoked exclusively by /usr/local/bin/cert-listener.php.
#
# Usage:
#   provision-cert.sh <domain> [--force]
#
# Without --force: certbot --keep-until-expiring (idempotent / no-op
# when cert is fresh). With --force: certbot --force-renewal (always
# issues a new cert). Only the listener's /reissue endpoint passes
# --force.
#
# Concurrency:
#   - Per-domain flock on /var/lock/cert-provision-<domain>.lock
#     (-n, fail-fast on contention) — prevents same-domain double-runs.
#   - GLOBAL flock on /var/lock/nginx-mutate.lock around the
#     mv → nginx -t → reload section (-w 30, wait up to 30s) — prevents
#     races with remove-cert.sh and the certbot-renew cron --post-hook.
#
# Exit codes:
#     0  success (JSON status=issued)
#     1  invalid input or generic failure (JSON status=failed)
#     2  per-domain lock held (JSON status=failed)
#     4  nginx-mutate lock acquisition timeout (JSON status=lock_timeout)
#
# Outputs:
#   - stdout: a single JSON document, the body of the listener's response.
#   - /var/log/cert-provision.log: timestamped diagnostic log lines
#     (also echoed to stderr so the listener's proc_open captures them).
#
# Required env (forwarded by listener):
#   CERT_CONTACT_EMAIL    e.g. ops@kynexsolutions.com
#   CERT_LE_SERVER        ACME directory URL (staging or prod)

set -u
set -o pipefail

DOMAIN="${1:-}"
FORCE_FLAG="${2:-}"
TEMPLATE="/usr/local/share/cert-listener/custom-domain.conf.tpl"
SITES_DIR="/etc/nginx/sites-enabled"
WEBROOT="/var/www/certbot/www"
LOCK_DIR="/var/lock"
LOCK_FILE="${LOCK_DIR}/cert-provision-${DOMAIN}.lock"
NGINX_LOCK="${LOCK_DIR}/nginx-mutate.lock"
NGINX_LOCK_WAIT=30
LOG_FILE="/var/log/cert-provision.log"
EXPECTED_V4="178.104.180.160"
EXPECTED_V6="2a01:4f8:c014:4657::1"

# ── Helpers ─────────────────────────────────────────────────────────

log() {
    local line
    line="[$(date -Iseconds)] [$DOMAIN] $*"
    # Append to log file AND mirror to stderr so the listener captures it.
    printf '%s\n' "$line" >> "$LOG_FILE"
    printf '%s\n' "$line" >&2
}

# emit STATUS [error_message] [extra_json_fragment]
emit() {
    local status="$1"; local err="${2:-}"; local extra="${3:-}"
    printf '{"status":"%s"' "$status"
    if [ -n "$err" ]; then
        # JSON-escape with jq if present; minimal manual escape otherwise.
        if command -v jq >/dev/null 2>&1; then
            printf ',"error":%s' "$(jq -Rn --arg s "$err" '$s')"
        else
            printf ',"error":"%s"' "${err//\"/\\\"}"
        fi
    fi
    if [ -n "$extra" ]; then
        printf ',%s' "$extra"
    fi
    printf '}\n'
}

# ── Validation ──────────────────────────────────────────────────────

if [ -z "$DOMAIN" ]; then
    emit "failed" "missing domain argument"
    exit 1
fi

if ! [[ "$DOMAIN" =~ ^([a-z0-9]([a-z0-9-]*[a-z0-9])?\.)+[a-z]{2,}$ ]]; then
    emit "failed" "invalid domain format: $DOMAIN"
    exit 1
fi

if [ -z "${CERT_CONTACT_EMAIL:-}" ] || [ -z "${CERT_LE_SERVER:-}" ]; then
    emit "failed" "missing CERT_CONTACT_EMAIL or CERT_LE_SERVER env"
    exit 1
fi

# ── Per-domain concurrency guard (fail-fast) ────────────────────────

mkdir -p "$LOCK_DIR"
exec 200>"$LOCK_FILE"
if ! flock -n 200; then
    log "Another provisioning run is in progress for $DOMAIN — aborting"
    emit "failed" "another provisioning run is in progress for $DOMAIN"
    exit 2
fi

log "Acquired per-domain lock $LOCK_FILE; force=${FORCE_FLAG:-(none)}"

# ── DNS pre-check ───────────────────────────────────────────────────

A_RECORDS=$(dig +short A    "$DOMAIN" 2>/dev/null || true)
AAAA_RECORDS=$(dig +short AAAA "$DOMAIN" 2>/dev/null || true)

dns_ok=0
echo "$A_RECORDS"    | grep -qx "$EXPECTED_V4" && dns_ok=1
echo "$AAAA_RECORDS" | grep -qx "$EXPECTED_V6" && dns_ok=1

if [ "$dns_ok" -ne 1 ]; then
    log "DNS pre-check failed. A=[${A_RECORDS//$'\n'/,}] AAAA=[${AAAA_RECORDS//$'\n'/,}]"
    emit "dns_mismatch" "Domain $DOMAIN does not resolve to this server (expected A=$EXPECTED_V4 or AAAA=$EXPECTED_V6)"
    exit 0
fi

log "DNS pre-check passed"

# ── certbot ─────────────────────────────────────────────────────────

if [ "$FORCE_FLAG" = "--force" ]; then
    log "Force mode: certbot --force-renewal"
    CERTBOT_FRESHNESS_ARG="--force-renewal"
else
    log "Idempotent mode: certbot --keep-until-expiring"
    CERTBOT_FRESHNESS_ARG="--keep-until-expiring"
fi

CERTBOT_OUT=$(/usr/bin/certbot certonly \
    --webroot --webroot-path "$WEBROOT" \
    --domain "$DOMAIN" \
    --email "$CERT_CONTACT_EMAIL" \
    --agree-tos --no-eff-email \
    --key-type ecdsa \
    "$CERTBOT_FRESHNESS_ARG" \
    --non-interactive \
    --server "$CERT_LE_SERVER" 2>&1)
CERTBOT_EXIT=$?

log "certbot exit=$CERTBOT_EXIT; head=$(printf '%s' "$CERTBOT_OUT" | tr '\n' ' ' | head -c 400)"

if [ "$CERTBOT_EXIT" -ne 0 ]; then
    if printf '%s' "$CERTBOT_OUT" | grep -qi "too many certificates\|rate limit"; then
        emit "rate_limited" "$(printf '%s' "$CERTBOT_OUT" | tail -5 | tr '\n' ' ')"
        exit 0
    fi
    emit "failed" "certbot failed (exit $CERTBOT_EXIT): $(printf '%s' "$CERTBOT_OUT" | tail -5 | tr '\n' ' ')"
    exit 1
fi

LIVE_DIR="/etc/letsencrypt/live/$DOMAIN"
if [ ! -f "$LIVE_DIR/fullchain.pem" ] || [ ! -f "$LIVE_DIR/privkey.pem" ]; then
    emit "failed" "certbot reported success but cert files are missing in $LIVE_DIR"
    exit 1
fi

# ── nginx block + test + reload (under global mutate lock) ─────────
#
# Render template into a tempfile in /tmp (NOT in sites-enabled/, so
# nginx never sees it during the staging phase). Then take the global
# mutate lock with a 30s timeout and do cmp / mv / test / reload as
# one atomic sequence.

TARGET="$SITES_DIR/custom-${DOMAIN}.conf"
TMP=$(mktemp "/tmp/cert-stage-${DOMAIN}.XXXXXX")
ISSUED_AT=$(date -Iseconds)

sed -e "s|__DOMAIN__|${DOMAIN}|g" \
    -e "s|__ISSUED_AT__|${ISSUED_AT}|g" \
    "$TEMPLATE" > "$TMP"

# Acquire the global nginx mutate lock. Wait up to NGINX_LOCK_WAIT
# seconds. Fail-loud if not acquired (do NOT silently bypass).
exec 201>"$NGINX_LOCK"
if ! flock -w "$NGINX_LOCK_WAIT" 201; then
    log "Could not acquire $NGINX_LOCK within ${NGINX_LOCK_WAIT}s"
    rm -f "$TMP"
    emit "lock_timeout" "could not acquire nginx-mutate lock within ${NGINX_LOCK_WAIT}s; another nginx mutation/reload may be stuck"
    exit 4
fi

log "Acquired global nginx-mutate lock"

# Inside the global lock: nothing else can mv into sites-enabled/ or
# run nginx -s reload until we release.

NGINX_CONF_CHANGED=0

if [ -f "$TARGET" ] && cmp -s "$TMP" "$TARGET"; then
    log "nginx conf unchanged for $DOMAIN; removing staged temp"
    rm -f "$TMP"
else
    mv "$TMP" "$TARGET"
    chmod 644 "$TARGET"
    NGINX_CONF_CHANGED=1
    log "Installed $TARGET"
fi

NGINX_TEST=$(/usr/sbin/nginx -t 2>&1)
NGINX_EXIT=$?

if [ "$NGINX_EXIT" -ne 0 ]; then
    log "nginx -t failed: $NGINX_TEST"
    if [ "$NGINX_CONF_CHANGED" -eq 1 ]; then
        log "Removing newly-written conf and re-testing"
        rm -f "$TARGET"
        NGINX_TEST_AFTER=$(/usr/sbin/nginx -t 2>&1)
        NGINX_EXIT_AFTER=$?
        flock -u 201 2>/dev/null || true
        if [ "$NGINX_EXIT_AFTER" -ne 0 ]; then
            emit "failed" "nginx -t failing for unrelated reason; aborting (left other configs intact): $(printf '%s' "$NGINX_TEST_AFTER" | tail -2 | tr '\n' ' ')"
            exit 1
        fi
        emit "failed" "nginx -t rejected our new conf for $DOMAIN: $(printf '%s' "$NGINX_TEST" | tail -3 | tr '\n' ' ')"
        exit 1
    fi
    flock -u 201 2>/dev/null || true
    emit "failed" "nginx -t failing pre-existing: $(printf '%s' "$NGINX_TEST" | tail -3 | tr '\n' ' ')"
    exit 1
fi

if [ "$NGINX_CONF_CHANGED" -eq 1 ]; then
    /usr/sbin/nginx -s reload 2>&1 | tee -a "$LOG_FILE" >&2
    log "nginx reloaded"
fi

flock -u 201 2>/dev/null || true

# ── Compute cert expiry for the caller ──────────────────────────────

EXPIRES_ISO=""
if command -v openssl >/dev/null 2>&1; then
    EXPIRES_RAW=$(openssl x509 -in "$LIVE_DIR/fullchain.pem" -noout -enddate 2>/dev/null | sed 's/^notAfter=//')
    if [ -n "$EXPIRES_RAW" ]; then
        EXPIRES_ISO=$(date -d "$EXPIRES_RAW" -Iseconds 2>/dev/null || true)
    fi
fi

EXTRA=""
if [ -n "$EXPIRES_ISO" ]; then
    EXTRA="\"cert_expires_at\":\"$EXPIRES_ISO\""
fi

emit "issued" "" "$EXTRA"
exit 0
```

```bash
#!/usr/bin/env bash
#
# remove-cert.sh — clean up nginx conf + cert for a removed custom
# domain. Best-effort; never errors hard. Output: JSON on stdout.
#
# Concurrency: the rm + nginx -t + reload sequence is protected by the
# same /var/lock/nginx-mutate.lock that provision-cert.sh uses. The
# certbot delete runs OUTSIDE the lock — it doesn't touch nginx state.
#
# Exit codes:
#     0  success (JSON status=removed)
#     1  invalid input
#     4  nginx-mutate lock acquisition timeout (JSON status=lock_timeout)

set -u

DOMAIN="${1:-}"
SITES_DIR="/etc/nginx/sites-enabled"
NGINX_LOCK="/var/lock/nginx-mutate.lock"
NGINX_LOCK_WAIT=30
LOG_FILE="/var/log/cert-remove.log"

log() {
    local line
    line="[$(date -Iseconds)] [${DOMAIN:-?}] $*"
    printf '%s\n' "$line" >> "$LOG_FILE"
    printf '%s\n' "$line" >&2
}

if [ -z "$DOMAIN" ] || ! [[ "$DOMAIN" =~ ^([a-z0-9]([a-z0-9-]*[a-z0-9])?\.)+[a-z]{2,}$ ]]; then
    echo '{"status":"failed","error":"invalid domain"}'
    exit 1
fi

TARGET="$SITES_DIR/custom-${DOMAIN}.conf"
REMOVED_CONF=0
REMOVED_CERT=0
ERROR=""

# Acquire global mutate lock around rm + test + reload. Fail-loud if
# we can't get it within the timeout.
exec 201>"$NGINX_LOCK"
if ! flock -w "$NGINX_LOCK_WAIT" 201; then
    log "Could not acquire $NGINX_LOCK within ${NGINX_LOCK_WAIT}s"
    echo '{"status":"lock_timeout","error":"could not acquire nginx-mutate lock within '"$NGINX_LOCK_WAIT"'s; another nginx mutation/reload may be stuck"}'
    exit 4
fi

log "Acquired global nginx-mutate lock"

if [ -f "$TARGET" ]; then
    rm -f "$TARGET" && REMOVED_CONF=1
    log "Removed $TARGET"
fi

if /usr/sbin/nginx -t >/dev/null 2>&1; then
    /usr/sbin/nginx -s reload 2>&1 | tee -a "$LOG_FILE" >&2
    log "nginx reloaded"
else
    ERROR="nginx -t failed after removing conf"
    log "$ERROR"
fi

flock -u 201 2>/dev/null || true

# certbot delete is idempotent. Outside the nginx lock — pure
# /etc/letsencrypt operation.
CERTBOT_OUT=$(/usr/bin/certbot delete --cert-name "$DOMAIN" --non-interactive 2>&1)
CERTBOT_EXIT=$?
if [ "$CERTBOT_EXIT" -eq 0 ]; then
    REMOVED_CERT=1
    log "certbot delete succeeded"
else
    log "certbot delete exit=$CERTBOT_EXIT (often expected if cert already absent)"
fi

printf '{"status":"removed","conf_removed":%d,"cert_removed":%d' "$REMOVED_CONF" "$REMOVED_CERT"
if [ -n "$ERROR" ]; then printf ',"error":"%s"' "${ERROR//\"/\\\"}"; fi
printf '}\n'
exit 0
```

### 2.5 `/var/www/kynex/docker/cert-listener.php` (8.9 kB)

```php
<?php
/**
 * cert-listener.php — minimal HTTP listener for cert provisioning.
 *
 * Phase 1.5. Run via:
 *   php -S 0.0.0.0:9090 /usr/local/bin/cert-listener.php
 * Supervised by /etc/supervisor/conf.d/kynex.conf [program:cert-listener].
 * Port 9090 is NOT exposed in /var/www/kynex/docker-compose.yml's
 * `ports:` — listener is reachable only on the kynex_kynex docker
 * network, never from the host.
 *
 * Endpoints (POST, JSON body):
 *   /provision  { "domain": "..." }   — idempotent issue / no-op renew
 *   /reissue    { "domain": "..." }   — forced re-issue
 *                                       REQUIRES additional header
 *                                       X-Cert-Reissue-Confirm: true
 *   /remove     { "domain": "..." }
 *
 * Auth: every request must carry header
 *   X-Cert-Listener-Secret: <SHARED_CERT_LISTENER_SECRET from /var/www/.env>
 * compared with hash_equals (constant-time).
 *
 * /reissue requires the additional X-Cert-Reissue-Confirm: true header
 * — defence in depth so a buggy client (or future code) can't burn an
 * LE rate-limit slot by accident.
 *
 * Outputs JSON on stdout; HTTP 200 unless misuse (401/400/404/500).
 *
 * Logging: stderr from this script and from spawned scripts is captured
 * by supervisord into /var/log/cert-listener.log. The scripts also
 * append to /var/log/cert-provision.log and /var/log/cert-remove.log.
 */

declare(strict_types=1);

// ── Load env from /var/www/.env (mounted by compose) ────────────────
//
// kynex-app's own /var/www/.env is the single source of truth for
// SHARED_CERT_LISTENER_SECRET, CERT_CONTACT_EMAIL, CERT_LE_SERVER. We
// read it directly here so this listener doesn't depend on supervisord
// env-injection and `php -S` doesn't need any wrapper. Read once at
// the top of every request — supervised PHP server forks per request,
// so the read cost is negligible and a `supervisorctl restart
// cert-listener` after secret rotation is enough to pick up new values.
$dotenv = function (string $path): array {
    $out = [];
    if (! is_readable($path)) {
        return $out;
    }
    $lines = @file($path, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES) ?: [];
    foreach ($lines as $line) {
        $line = ltrim($line);
        if ($line === '' || str_starts_with($line, '#')) {
            continue;
        }
        if (! str_contains($line, '=')) {
            continue;
        }
        [$k, $v] = explode('=', $line, 2);
        $k = trim($k);
        $v = trim($v);
        // Strip surrounding quotes.
        if (strlen($v) >= 2
            && (($v[0] === '"' && $v[-1] === '"')
                || ($v[0] === "'" && $v[-1] === "'"))) {
            $v = substr($v, 1, -1);
        }
        $out[$k] = $v;
    }
    return $out;
};

$env = $dotenv('/var/www/.env');

$secret    = $env['SHARED_CERT_LISTENER_SECRET'] ?? (getenv('SHARED_CERT_LISTENER_SECRET') ?: '');
$leServer  = $env['CERT_LE_SERVER']
    ?? (getenv('CERT_LE_SERVER')
        ?: 'https://acme-v02.api.letsencrypt.org/directory');
$leEmail   = $env['CERT_CONTACT_EMAIL']
    ?? (getenv('CERT_CONTACT_EMAIL') ?: '');

// ── Per-request setup ───────────────────────────────────────────────

$method         = $_SERVER['REQUEST_METHOD'] ?? '';
$path           = parse_url($_SERVER['REQUEST_URI'] ?? '/', PHP_URL_PATH) ?: '/';
$header         = $_SERVER['HTTP_X_CERT_LISTENER_SECRET'] ?? '';
$reissueConfirm = $_SERVER['HTTP_X_CERT_REISSUE_CONFIRM'] ?? '';

header('Content-Type: application/json');
header('X-Listener-Version: phase-1.5');

$logLine = static function (string $msg): void {
    fwrite(STDERR, '[' . date('c') . '] ' . $msg . "\n");
};

// ── Auth ────────────────────────────────────────────────────────────

if ($secret === '' || ! hash_equals($secret, $header)) {
    http_response_code(401);
    $logLine("auth-fail path=$path remote=" . ($_SERVER['REMOTE_ADDR'] ?? '?'));
    echo json_encode(['status' => 'failed', 'error' => 'unauthorized']);
    return;
}

if ($method !== 'POST') {
    http_response_code(405);
    echo json_encode(['status' => 'failed', 'error' => 'method not allowed']);
    return;
}

// ── Parse body ──────────────────────────────────────────────────────

$raw  = file_get_contents('php://input') ?: '';
$body = json_decode($raw, true);
if (! is_array($body) || ! isset($body['domain']) || ! is_string($body['domain'])) {
    http_response_code(400);
    echo json_encode(['status' => 'failed', 'error' => 'missing domain']);
    return;
}
$domain = $body['domain'];

if (! preg_match('/^([a-z0-9]([a-z0-9-]*[a-z0-9])?\.)+[a-z]{2,}$/', $domain)) {
    http_response_code(400);
    echo json_encode(['status' => 'failed', 'error' => 'invalid domain']);
    return;
}

// ── Endpoint dispatch ───────────────────────────────────────────────
//
// /reissue requires the confirmation header; we reject before spawning
// the script so the misuse never reaches certbot.

$scriptArgs = null;

switch ($path) {
    case '/provision':
        $scriptArgs = ['/usr/local/bin/provision-cert.sh', $domain];
        break;

    case '/reissue':
        if (! hash_equals('true', $reissueConfirm)) {
            http_response_code(400);
            $logLine("reissue-no-confirm path=$path domain=$domain");
            echo json_encode([
                'status' => 'failed',
                'error'  => '/reissue requires header X-Cert-Reissue-Confirm: true',
            ]);
            return;
        }
        $scriptArgs = ['/usr/local/bin/provision-cert.sh', $domain, '--force'];
        break;

    case '/remove':
        $scriptArgs = ['/usr/local/bin/remove-cert.sh', $domain];
        break;

    default:
        http_response_code(404);
        echo json_encode(['status' => 'failed', 'error' => 'unknown endpoint']);
        return;
}

$logLine(sprintf(
    'dispatch path=%s domain=%s force=%s',
    $path,
    $domain,
    in_array('--force', $scriptArgs, true) ? '1' : '0'
));

// ── Spawn script ────────────────────────────────────────────────────

$descriptors = [
    0 => ['pipe', 'r'],
    1 => ['pipe', 'w'],
    2 => ['pipe', 'w'],
];

$childEnv = [
    'PATH'                => '/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin',
    'CERT_CONTACT_EMAIL'  => $leEmail,
    'CERT_LE_SERVER'      => $leServer,
];

$proc = proc_open($scriptArgs, $descriptors, $pipes, null, $childEnv);

if (! is_resource($proc)) {
    http_response_code(500);
    $logLine("spawn-fail path=$path domain=$domain");
    echo json_encode(['status' => 'failed', 'error' => 'failed to spawn script']);
    return;
}

fclose($pipes[0]);
$stdout = stream_get_contents($pipes[1]); fclose($pipes[1]);
$stderr = stream_get_contents($pipes[2]); fclose($pipes[2]);
$exit   = proc_close($proc);

$logLine(sprintf(
    'done path=%s domain=%s exit=%d stdout=%s',
    $path,
    $domain,
    $exit,
    substr(trim($stdout), 0, 200)
));

// ── Parse script output ─────────────────────────────────────────────
//
// The script is expected to emit a single JSON document on stdout. We
// pass that through to the caller. If the JSON parse fails we synthesize
// a response based on exit code:
//   - exit 4 (nginx-mutate lock timeout) → status=lock_timeout
//   - any other → status=failed (with stdout/stderr captured)

$decoded = json_decode($stdout, true);

if (! is_array($decoded)) {
    if ($exit === 4) {
        // Distinct exit code 4 maps to lock_timeout. Belt-and-suspenders
        // for the case where the script crashed mid-emit.
        http_response_code(500);
        echo json_encode([
            'status'    => 'lock_timeout',
            'error'     => 'script exit 4 — nginx-mutate lock acquisition timeout (no JSON)',
            'exit_code' => $exit,
            'stderr'    => substr($stderr, 0, 1000),
        ]);
        return;
    }
    http_response_code(500);
    echo json_encode([
        'status'    => 'failed',
        'error'     => 'script did not return JSON',
        'stdout'    => substr($stdout, 0, 1000),
        'stderr'    => substr($stderr, 0, 1000),
        'exit_code' => $exit,
    ]);
    return;
}

// Annotate with exit code so the Job log can correlate.
$decoded['exit_code'] = $exit;
echo json_encode($decoded);
```

### 7.2 DNS pre-check (provision only)

Lines 121-132 of `provision-cert.sh`:

```bash
A_RECORDS=$(dig +short A    "$DOMAIN" 2>/dev/null || true)
AAAA_RECORDS=$(dig +short AAAA "$DOMAIN" 2>/dev/null || true)

dns_ok=0
echo "$A_RECORDS"    | grep -qx "$EXPECTED_V4" && dns_ok=1
echo "$AAAA_RECORDS" | grep -qx "$EXPECTED_V6" && dns_ok=1

if [ "$dns_ok" -ne 1 ]; then
    log "DNS pre-check failed. A=[${A_RECORDS//$'\n'/,}] AAAA=[${AAAA_RECORDS//$'\n'/,}]"
    emit "dns_mismatch" "Domain $DOMAIN does not resolve to this server (expected A=$EXPECTED_V4 or AAAA=$EXPECTED_V6)"
    exit 0
fi
```

Refuses to call certbot if neither IPv4 nor IPv6 of the domain matches
this server's `178.104.180.160` / `2a01:4f8:c014:4657::1`. Saves an
LE rate-limit slot on misconfigured DNS.

### 7.3 Rollback paths

#### `provision-cert.sh` lines 215-235 — nginx -t failure rollback

```bash
if [ "$NGINX_EXIT" -ne 0 ]; then
    log "nginx -t failed: $NGINX_TEST"
    if [ "$NGINX_CONF_CHANGED" -eq 1 ]; then
        log "Removing newly-written conf and re-testing"
        rm -f "$TARGET"
        NGINX_TEST_AFTER=$(/usr/sbin/nginx -t 2>&1)
        NGINX_EXIT_AFTER=$?
        flock -u 201 2>/dev/null || true
        if [ "$NGINX_EXIT_AFTER" -ne 0 ]; then
            emit "failed" "nginx -t failing for unrelated reason; aborting (left other configs intact): ..."
            exit 1
        fi
        emit "failed" "nginx -t rejected our new conf for $DOMAIN: ..."
        exit 1
    fi
    flock -u 201 2>/dev/null || true
    emit "failed" "nginx -t failing pre-existing: ..."
    exit 1
fi
```

If `nginx -t` rejects the proposed config:
1. If we wrote a new file, `rm -f` it (only the one we wrote, never glob-deleted).
2. Re-run `nginx -t` — if it now passes, the failure WAS our file → emit detailed error.
3. If it STILL fails, the kynex-app container has pre-existing nginx breakage we didn't cause → emit a different error and leave OTHER domains' confs intact.

The script never reloads nginx in this path. The on-disk state is restored to whatever it was before our run (modulo any write to the cert dir, which is independent of nginx state).

#### `provision-cert.sh` lines 198-209 — cmp-then-mv idempotence

```bash
if [ -f "$TARGET" ] && cmp -s "$TMP" "$TARGET"; then
    log "nginx conf unchanged for $DOMAIN; removing staged temp"
    rm -f "$TMP"
else
    mv "$TMP" "$TARGET"
    chmod 644 "$TARGET"
    NGINX_CONF_CHANGED=1
    log "Installed $TARGET"
fi
```

Re-running the script for an already-issued domain is a no-op:
`certbot --keep-until-expiring` skips the cert step, `cmp -s` detects
the conf is identical, no `mv`, no reload, no log noise.

#### `remove-cert.sh` lines 53-66 — best-effort cleanup

The `rm -f` is targeted at the path constructed from `$DOMAIN` (never a
glob), `nginx -t` is checked before reload (so a broken state isn't
made worse), and `certbot delete` runs outside the lock (it's a pure
`/etc/letsencrypt` operation). All steps are individually safe to
re-run.
