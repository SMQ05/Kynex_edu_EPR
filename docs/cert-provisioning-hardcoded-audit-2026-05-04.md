### §A — Listener bind port: option to make env-driven

Pattern: `command=php -S 0.0.0.0:%(ENV_CERT_LISTENER_BIND)s /usr/local/bin/cert-listener.php` in `supervisor.conf`. Requires the env to be present in supervisord's process env, which means we'd need to add `set -a; . /var/www/.env; set +a` to entrypoint.sh before `exec supervisord`. Three small edits. Lock-in cost: today the listener is reachable only on the docker network at port 9090; if a future deployment puts cert-listener on a different port, you'd need an image rebuild without this fix.

### §B — Backend proxy host/port: option to make env-driven

Add `__BACKEND__` placeholder to `custom-domain.conf.tpl`, replace via additional `sed` line in `provision-cert.sh`, source from `$CERT_BACKEND` env (default `http://kynexedu-app:80`). Listener forwards via `$childEnv`.

## Summary — fix-before-5 batch

In priority order:

1. **`'kynexedu.com'` CNAME target hardcoded twice** (`Service:117,181` + `DomainsRelationManager:129`). Add `cname_target` to `config/cert.php`, env `CERT_CNAME_TARGET`, default `kynexedu.com`. Update three call sites. **High priority** — operator-facing, three copies, drift-prone.

2. **`NGINX_LOCK_WAIT=30` hardcoded in three places** (`provision-cert.sh:49`, `remove-cert.sh:20`, `certbot-renew.cron:12`). Add to `/var/www/kynex/.env`, listener forwards via `$childEnv`, scripts use `${NGINX_LOCK_WAIT:-30}`, cron uses `${NGINX_LOCK_WAIT}` (cron has `SHELL=/bin/bash` so vars expand). **High priority** — three places drift-prone.

3. **`addDays(14)` renewal threshold hardcoded twice** (`Job:70`, `Command:91`). Add `renewal_sweep_days` to `config/cert.php`, env `CERT_RENEWAL_SWEEP_DAYS`, default 14. **High priority** — two copies, drift-prone.

4. **Service remove-call timeout fallback differs from Job** (`Service:162` uses 60 fallback, Job `:85` uses 120). Unify both to `(int) config('cert.listener_timeout', 120)` — single source of truth. **Medium priority** — semantic bug today.

5. **Job `$tries`, `$backoff`, `$timeout` magic numbers** (`Job:41-43`). Replace with `config('cert.job_tries', 3)` etc; pull values via constructor or via Laravel's `retryUntil()` method. **Low priority** — single-file constants, low drift risk.

6. **Verification token TTL `subDays(7)`** (`Command:33`). Add `verification_token_ttl_days` to `config/cert.php`. **Low priority** — single-file.

7. **`connectTimeout(5)` hardcoded twice** (`Job:117`, `Service:163`). Add `cert.listener_connect_timeout` config key with default 5. **Low priority**.

### Optional (won't block sub-phase 5)

8. **Listener bind port** (`supervisor.conf:64` `0.0.0.0:9090`). Requires supervisord env-substitution + entrypoint env source. **Defer** unless you want it now.

9. **Backend proxy hostname/port** (`custom-domain.conf.tpl:21` `http://kynexedu-app:80`). Add `__BACKEND__` placeholder + `sed` substitution + `$CERT_BACKEND` env. **Defer** unless multi-instance is on the near horizon.

10. **Webroot path** `/var/www/certbot/www`. Three-way pinning: change requires script + Dockerfile + compose. **Defer** — single source of truth refactor, not urgent.
